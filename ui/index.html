Auto-apply bar

How sure the agent must be before money moves onto an invoice without a person looking. This is a product decision. Lower it and more payments reconcile themselves; the code guardrails still have to agree either way.

How a payment flows

  1. Code

    Gather evidence

    Recover invoice numbers from messy memos, match the payer against names this customer has paid from before, find exact amounts and invoice combinations that sum to the deposit.

  2. Model

    Propose

    Decide what the payment is: which invoices, any fee or partial, a calibrated confidence, and one sentence a business owner can read.

  3. Code

    Decide

    Auto-apply only if amounts reconcile to the cent, one customer, two independent signals (payer and reference or amount), and no partials or overpayments.

  4. Product

    Act

    Apply and log it, or put it in the queue with the suggested match and the reason it stopped.

What the eval says
